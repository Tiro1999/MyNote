# MyNote
I´d love to have a highly custamizable solution for my personal notes and therefore an alternative for commonly used software that is always missing something.
You can run this 100% locally or host it yourself.

Status : In development


## Ideas
- Magic the Gathering card organizer around the s[cryfall API](https://scryfall.com/docs/api/cards/search) and with common .csv backend storage
- General Component storage organizer with import/export while relying on an .csv backend
- feel free to create "Enhancement" [Issue](https://github.com/Tiro1999/MyNote/issues?q=is%3Aissue) if you have any ideas yourself

## Requirements:
- fully flexible in every possible integration (local, server hosting, )
- full degree of freedome on placing text and picutures on the canvas
- Cascade content just like you need it
- add text templates with **/cmd**
- hyperlinks are supported
- fully local storage
- Windows/Linux/Mac Installer
